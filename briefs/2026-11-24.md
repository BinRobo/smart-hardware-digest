## 1. HachimoDock（哈基米机）

- 品类：智能硬件 / 桌面工具（给 AI Agent 用的实体小屏）
- 来源：立创开源硬件平台、GitHub、什么值得买（非头部众筹）
- 链接：[GitHub](https://github.com/ai-maker-lab/HachimoDock) · [立创项目页](https://oshwhub.com/eda_gqvzlprk/project_cnbmkbjc) · [什么值得买 11-06 复刻账](https://post.smzdm.com/p/ak832608/) · [11-15 复刻要点](https://post.smzdm.com/p/ak833zg9/)

一块约 2.8 英寸的开源桌面小屏，把 Claude Code、Codex 一类 CLI Agent 的思考、执行、等待确认和报错，变成桌上宠物的表情和语音入口。增量不是再做一个 AI 桌宠，而是把「第二个工位屏幕」做成一份能复刻的物料清单和固件。

解决谁的问题：经常并排跑多个 Agent 窗口的人。现在要在编辑器、终端和聊天之间来回切，才能知道任务卡在哪、要不要批准；有人用手机看通知，有人用宏垫或遥控器凑合说话。

需求证据：仓库和立创页都是 2026-06-10 就开了，安静了四个多月。什么值得买 11 月 6 日写到，它在 10 月 24–25 日杭州观猹大会展出后才出圈，当天上午 GitHub 为 841 星、79 分支；所用开发板和屏幕已经涨价、缺货。11 月 15 日继续跟进：官方口径约 150 元，社区有人买到 220 元，群内整套配件包约 170 元，并总结了排线、数据线、烧录环境和外壳代打四个复刻坑。这是典型的「开源被跟做」。今日用 GitHub API 核到官方仓 `ai-maker-lab/HachimoDock` 为 **1079 星、127 分支、41 个未关 Issue**，最近一次推送为 2026-11-23 21:03（UTC+8）。立创原页今日抓取超时，浏览和下载次数不以未核到的数字写进正文。

热度信号：看的不是筹款额，而是复刻把零件买贵、星标还在涨。11 月 6 日至今日，星标从 841 增至 1079，分支从 79 增至 127。嘉立创页标复刻成本 150 元，同一页物料加总其实是 167.23 元，动手做过的人普遍报到 230–250 元。

可行性 / 价格：没有官方整机零售。需自购微雪 ESP32-P4 开发板、2.8 寸屏等，再 3D 打印外壳，USB 供电即用。现货取决于零件库存。

主要风险：许可证表述冲突——GitHub API 今日仍显示许可证为 Other / 未断言；什么值得买 11 月 6 日写到仓库曾挂非商业许可，立创页写 GPL-3.0，想做套件卖的人需要先问作者。多数功能要连电脑、要插电；烧录包分芯片版本，烧错会变砖。

同一需求的商业化对照是 SlashVibe，见文末跟踪，今天不单列，以免把一条需求写两遍。

## 2. HiFi-ESP32-Input

- 品类：智能硬件 / 开源桌面音频采集板
- 来源：Tindie（小批量，今日已打开产品页）；Sonocotta 官方说明
- 链接：[Tindie 产品页](https://www.tindie.com/products/sonocotta/hifi-esp32-input/) · [Sonocotta 11-17 说明](https://sonocotta.com/hifi-esp32-input-tindie-beta/) · [GitHub 需求帖](https://github.com/music-assistant/local-audio-addon/issues/23) · [Music Assistant 2.10 博文](https://www.music-assistant.io/blog/2026/08/26/music-assistant-2-10/)

把播放板里的 DAC 换成 PCM1863 ADC：唱机（需唱放）、CD、卡座、电视耳机口这些模拟源，可以变成 Music Assistant 的 Sendspin 音源，再同步到全屋音箱。增量在补上开源多房间系统里长期缺的「模拟源 → 网络」这一头，不是再做一块 USB 声卡。

解决谁的问题：已经在用 Music Assistant / Home Assistant 做多房间播放，但唱机、磁带和电视声音还进不了同一套系统的人。现在常见的凑合是 Behringer 一类 USB 声卡，或树莓派上的 HiFiBerry ADC HAT。

需求证据：Music Assistant 2026-08-26 的 2.10 博文写得很直白：Sendspin 已经可以反向收流，「a turntable in the living room, for example, could stream to any speaker in the house. While no device supports this yet, Music Assistant has everything ready for the first one that does。」第二天，Hedda 在 GitHub issue #23 正式要线路输入，并列了 Behringer UCA/UFO 和 HiFiBerry ADC HAT 等现成凑合方案；该帖在 2026-11-20 仍有更新。制作方 11 月 17 日发文确认，这块板就是响应这一请求。

热度信号：定价 **$25**，首批只有 **10 块**，11 月 17 日上架，产品页写明 **Sold out since Nov 19, 2026**，大约两天售罄。这是小批量被买走，不是传播爆款。

可行性 / 价格：$25，作者自己说几乎只覆盖打样成本。原理图、PCB 和 ESPHome 配置按官方说明会开源。今日未能独立打开其 GitHub 仓库页，开源落地以作者声明为准。

主要风险：明确是第一版原型，给测试者用，不是成品；固件新，ESPHome 驱动还在上游评审；没有静音检测，选中的输入会一直推流；下一批规格和名称都可能改。

## 3. Tessera（原名 ESP Screens）

- 品类：智能硬件生态（便宜 ESP32 触摸屏 + 开源固件 / Home Assistant 插件）
- 来源：CNX Software（2026-11-23）；Home Assistant 社区；GitHub（非众筹）
- 链接：[CNX 11-23](https://www.cnx-software.com/2026/11/23/tessera-open-source-dashboard-for-home-assistant-runs-on-esp32-touchscreen-devkits/) · [GitHub](https://github.com/MaxGramser/homeassistant_espscreen) · [HA 原帖](https://community.home-assistant.io/t/introducing-esp-screens-beautiful-cheap-esp32-touch-screens-for-every-room-managed-from-home-assistant/1025191)

把 2.8–10.1 英寸的 CYD / Guition / Waveshare 触摸屏，变成可在 Home Assistant 里拖拽布局的房间控制屏：改磁砖后走 Wi-Fi 下发，不必再为每块屏维护一份 ESPHome YAML、也不用重新刷机。硬件是现成开发套件，增量在维护成本。

解决谁的问题：家里并不都想打开手机 App 翻仪表盘的人。商用墙板贵，旧安卓平板做 kiosk 不稳定，自己写 ESPHome 显示又太重。

需求证据：作者 2026-09-15 在 Home Assistant 论坛发帖，原话就是三条愿望——好看、改磁砖不必重编译、便宜到每个房间都能放一块。今日打开了该帖首页，原帖有 27 个赞；完整后续楼层未能一次点完，故不以总回复数作依据。CNX 11 月 23 日报道称，Guition 4 英寸屏「tested by over 3,000 users」，成功率通常接近 90%，并列为推荐型号。今日用 GitHub API 核到 [MaxGramser/homeassistant_espscreen](https://github.com/MaxGramser/homeassistant_espscreen) 为 **1285 星、212 分支、128 个未关 Issue**，最近一次推送为 2026-11-23 22:10（UTC+8），仓库当日 09:18 仍有更新。许可证为 AGPL-3.0。

热度信号：没有众筹额，看的是装机口径和持续发版。CYD 入门屏作者自己标到大约 €15。

可行性 / 价格：软件免费。硬件按现成屏采购，从约 2.8 英寸 CYD 到 10.1 英寸面板不等，支架需另买或 3D 打印。

主要风险：这不是一款整机 SKU，品控取决于各家屏幕，市面上还有控制器不同的仿款；作者一人维护，未关 Issue 已经过百；深度依赖 Home Assistant 和 ESPHome 的版本节奏。

## 4. Piccola CNC

- 品类：桌面工具（开源桌面铣床，兼做 PCB 隔离铣）
- 来源：Kickstarter（2026-11-17 上线；官方页今日 403）；今日新覆盖来自 CNX Software（11-23）和 Hackster（11-18）
- 链接：[CNX 11-23](https://www.cnx-software.com/2026/11/23/piccola-cnc-open-source-desktop-milling-machine-with-pcb-auto-leveling-and-integrated-cam/) · [Hackster 11-18](https://www.hackster.io/news/inmachines-launches-its-100-open-desktop-scale-piccola-cnc-mill-into-crowdfunding-f19ab8a74d76) · [Kicktraq](https://www.kicktraq.com/projects/inmachines/piccola-cnc/) · [Kickstarter 项目页](https://www.kickstarter.com/projects/inmachines/piccola-cnc)（今日未能打开，金额以 Kicktraq 为准）

德国 InMachines 的 150×150×70 mm 开源三轴桌面铣床，面向已经有 3D 打印机、还想自己切电路板和软金属件的人。不是再做一台改壳 3018：双 RP2350 把 grblHAL 运动控制和安全/传感器监督拆开，全轴滚珠丝杠，全机型都有接触式 PCB 调平，Ultimate 再加激光测距；CAM 接到已有的开源项目 EasyTrace5000 和 Kiri:Moto。公司称发货时公开机械、电子、固件和软件（计划包括 CERN-OHL-S-2.0、GPL-3.0、AGPL-3.0），但现在文件还没放出来。

解决谁的问题：电子爱好者和小实验室为了一两块验证板，现在要么等制板厂，要么用廉价 3018 自己啃、另学一套 CAM。这台机器把调平和 CAM 收进同一套软件，价格带也明显低于常见的闭源桌面铣床。

需求证据：场景本身长期存在，但今日未能在 r/hobbycnc 等版块稳定找到专门讨论帖，不能写成「社区已经热议」。更硬的信号是：76 名支持者人均承诺约 €1,571，买的是整机，不是周边。发起方 Daniele Ingrassia 先前有 BigFDM、Open Lab Starter Kit 等开源工具机先例。

热度信号：Kicktraq 今日页面为 **76 名支持者，已筹 €119,395 / 目标 €25,000（477%）**，周期 2026-11-17 至 12-15，还剩约 21 天。同月还有筹款额高得多的桌面 CNC 项目（如 ToolDance X1、Rownd 5X），传播热度可能被带偏，Piccola 应和它们对照看，而不是跟着金额走。

可行性 / 价格：Early Bird Basic / Pro / Ultimate 为 €1,091 / €1,511 / €1,679，均不含增值税和运费；预计 2027 年 7 月发货。

主要风险：交期长；开源文件要到首批发货才公开；CE 认证当时仍在进行；100–200W 主轴切铝只能浅刀、耗时长。

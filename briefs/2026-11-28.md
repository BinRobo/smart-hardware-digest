## 1. ANAVI I2C TPM 2.0

- 品类：智能硬件 / 开源安全扩展板（树莓派 I2C TPM）
- 来源：Crowd Supply（正在众筹）；ANAVI 官方博客（2026-11-26 宣布开筹）；需求来自其 SPI 版既有用户
- 链接：[Crowd Supply 项目页](https://www.crowdsupply.com/anavi-technology/anavi-i2c-tpm-2-0) · [官方开筹说明](https://blog.anavi.technology/anavi-i2c-tpm-2-0-crowdfunding-campaign-is-live-on-crowd-supply/) · [GitHub](https://github.com/AnaviTechnology/anavi-i2c-tpm-2.0) · [SPI 前作](https://www.crowdsupply.com/anavi-technology/anavi-tpm-2-0-for-raspberry-pi) · [FabScene 11-19](https://fabscene.com/new/news/anavi-i2c-tpm-2-0-raspberry-pi-crowd-supply/)

入选理由：不是新造一个加密狗，而是把已经出过货的 SPI 版 TPM 改成只占 5 个针脚的 I2C 版，把 SPI 腾出来给别的外设。板子 16.5×12.8 mm，芯片是 Infineon OPTIGA SLB 9673，官方树莓派内核已有 `tpm-slb9673` 设备树 overlay，2026-07-10 拿过 OSHWA 认证（BG000154），设计以 CC BY-SA 4.0 开源。众筹目标只有 1 美元，因为首批已经在保加利亚普罗夫迪夫做完组装和测试。

需求证据：

- 谁：在树莓派上做磁盘加密、设备认证或可信启动，又希望有硬件真随机数，但不想为此占掉 SPI 总线的人。
- 什么场景：把 TPM 插在 Pi 上，用官方 overlay 做全盘加密或密钥托管。SPI 版要用 17–26 号共 10 个针脚；I2C 版只占用 1、3、5、7、9。
- 如何判断需求真实：ANAVI 自己写明，I2C 版是应 SPI 版用户要求做的。SPI 版 Crowd Supply 检索快照仍显示已筹 **$3,214 / 目标 $1**，状态为可预购。I2C 版 GitHub 今日 API 为 **4 star、1 fork**，最近一次 push 仍是 2026-05-08；星不多，但前作已经出货，不是空设计。

热度信号：Crowd Supply 原页今天仍是 403，不能当成当场刷新的实时数。公开检索快照写的是已筹 **$510 / 目标 $1**，**9 名支持者**，已过线，剩余约 41 天（FabScene 11-19 报道筹款期至 2027-01-07）。档位是直插头 **$20**、弯插头 **$21**，美国运费 $8、其他地区 $18，计划 2027-03-18 发货。金额很小，只作参考。

主要风险：当前支持者很少，公开数字无法在原页复核；仓库几乎半年没推送；官方文档按评估板定位，不是消费成品；交期到明年 3 月。

## 2. Exaviz Cruiser Carrier Board v2.0

- 品类：智能硬件 / 桌面与边缘网关（树莓派 CM5 的 PoE NVR 底板）
- 来源：Exaviz 官方预购（约 2026-11-26 开放）；LinuxGizmos（11-26）、Hackster（11-27）报道
- 链接：[v2.0 预购页](https://www.exaviz.com/products/cruiser-carrier-board-v2-0/) · [v1.0 产品页](https://www.exaviz.com/products/cruiser-carrier-board-v1-0/) · [LinuxGizmos 11-26](https://linuxgizmos.com/cm5-carrier-board-has-8-port-poe-switch-and-dual-band-wi-fi-6/) · [Hackster 11-27](https://www.hackster.io/news/exaviz-updates-its-cruiser-eight-port-all-in-one-raspberry-pi-cm5-carrier-board-with-dual-band-wi-fi-0963f5261275)

入选理由：家庭或小现场要同时给摄像头供电并本地录像，通常得买一台 PoE 交换机，再接一台 NAS 或树莓派。Cruiser 把 8 口千兆 PoE+（总预算 120W）、2.5GbE 上联、M.2 NVMe、两路 SATA（可做硬件 RAID）和双 4K HDMI，放进一块 170×120 mm、可按 Mini-ITX 孔位安装的 CM5 底板。v2.0 的增量主要是无线从 ESP32-C6 换成双频 ESP32-C5，以及 48V 输入加了浪涌限制；形态本身在今年 2 月的 v1 已经成立，但这条产品线之前没进过日报，今天用预购开张来写。

需求证据：

- 谁：自己架 PoE 摄像头、门禁或无线 AP，又想在本地录像、最好还能跑 Home Assistant 的人。
- 什么场景：一根 48V 供电，摄像头直接插在底板上，录像写到 SATA 或 NVMe，CM5 上跑现有 VMS；M.2 也可选插 Hailo-8 做边缘检测。
- 如何判断需求真实：官方 v1.0 页面写明 Cruiser Lite 和 Cruiser Keel **目前缺货**，说明上一版已经有人在买，不是只发了产品页。公司还做了本地管理软件和 Home Assistant PoE 插件，但 GitHub `exavizco/ha-poe-plugin` 今日是 **0 star、1 fork**，插件本身还不热，不把它当成需求主证据。

热度信号：v2.0 Full 预购 **$159**（只含板，CM5 另买），第一批限 **100 块**，美国包邮，预计 2027 年 1 月下旬发货，发货前可全额取消。LinuxGizmos 和 Hackster 昨天到今天跟了报道。

主要风险：产品页仍在用 v1 照片；C5 版的 Zigbee 固件还没好；天线不附送，而且是 MHF IV，和 v1 的 MHF III 线不兼容；总价还要加上 CM5、48V 电源和硬盘；第一批只有 100 块，交期到明年 1 月。

## 3. Phosphor（刷在 Waveshare ESP32-S3-Touch-LCD-3.49 上的开源固件）

- 品类：智能硬件 / 桌面工具（把现成长条屏做成复古桌面钟和网络收音机）
- 来源：CNX Software（2026-11-27）；作者 Melih Koray 的开源仓库（非众筹）
- 链接：[GitHub](https://github.com/melihkoray/phosphor) · [项目页](https://melihkoray.github.io/phosphor/) · [CNX 11-27](https://www.cnx-software.com/2026/11/27/waveshare-esp32-s3-touch-lcd-3-49-gets-open-source-retro-firmware-with-clock-internet-radio-games/)

入选理由：这块 3.49 寸、640×172 的长条屏本来是开发套件，长得像货架标签或老音响的 VFD 窗。Phosphor 围着这个形状做了时钟闹钟、天气、网络收音机、专注计时和三个小游戏，并且认真做成 VFD / C64 / Amiga / Atari 2600 四种风格——不是换个配色，2600 风格甚至按「一行只有四种颜色」来画。Blackjack 用板载 IMU：敲一下桌子停牌，敲两下要牌。用 Chrome 或 Edge 从浏览器刷机，不用自己搭编译环境。

需求证据：

- 谁：想在桌上放一个长条信息窗或复古钟电台，但不想买成品智能相框，也不想从零写 UI 的人。
- 什么场景：买一块大约 30–43 美元的现成屏，刷上社区固件，当闹钟、收音机和摆件。和前几日写过的 TokenTV、HachimoDock 同属「桌面上要一块常亮小屏」，但这条走的是钟和电台，不是 Agent 状态。
- 如何判断需求真实：仓库 2026-11-20 建立，11-24 发到 v2.0.3。GitHub 今日 API 为 **104 star、9 fork、5 个未关 issue**，仓库页更新时间到 2026-11-28 09:09（UTC+8）。Adafruit 11-23 转过；CNX 11-27 评测下，有读者直接留言说已经按文中链接下单买板。

热度信号：硬件是现货。Waveshare 官网约 $29.99–$31.99，Amazon 约 $42.99，速卖通约 $35，另有 18650 / 锂电壳体。固件 GPL-3.0，最近一次代码推送是 2026-11-24。

主要风险：这是固件，不是新硬件；目前写死在这款分辨率和引脚上，不好移植；HTTP API 只适合内网，不能暴露到公网；V1 硬件兼容性作者还在等人反馈；从 1.x 升到 2.0 必须用 USB 线升级，不能走 Wi-Fi。

- 日期：2026-11-23（星期一）
- 时区：UTC+8
- 数据截至：约 09:40（UTC+8）

今天不再把名单交给头部众筹排行。Flipper One、Keychron Orca echo、ARANIX、InfiMech MX 仍在筹，昨天已经报过，这里只作跟踪，不重复占位。精选 4 条：一条是 Framework 刚开放预购的沙发键盘，候补和批次售罄是今天最硬的需求信号；一条是 SDR / Meshtastic 垂直站刚评到的树莓派四合一扩展板，小店现货预售、价格也不高；一条是刚过线的模块化 x86 掌机，形态有增量，但支持者很少；再补一条 Show HN 上的开源故事盒，用来说明「闭源内容玩具」这块是家长在自己动手绕。

## 周一来源复盘

本周优先补能暴露未满足需求的垂直渠道，而不是再加一层众筹榜。实际能用上的新入口：Retro Handhelds（掌机玩家会直接说自己做没做）、RTL-SDR.com（评论区比官网演示有用）、Framework 官方博客/产品页和 Phoronix（桌面外设的真实候补与讨论）、以及 Kickstarter China Tracker（只用来交叉核对国内团队在筹项目，不当需求判断）。Indiegogo 今天能打开，但 TypAir 的众筹页显示已取消、筹款为 €0，不能和官网预购页混写成「正在众筹」。Crowd Supply 连续第二天全站 403，Tinta 等项目只能看 LinuxGizmos、Hackster 和检索快照，公开快照仍写已筹 $0 / 0 名支持者，所以今天不把它写成一条正式入选。立创开源能打开活动页和部分项目，但正文抓取不稳定，没有达到「可验证小批量或扎实跟做」的入选线，先保留为固定扫描源。摩点仍被游戏《艾希：续》收官消息占据，没有达标硬件；有品是剃须刀、落地灯一类迭代，不选。京东众筹、恩山、RCGroups，以及 Reddit 多个垂直版块，今天仍然没能稳定抓到可引用的热帖，不假装覆盖到了。Kickstarter 项目页今天经常只有外壳或报 404，在筹数字以 Kicktraq 为准。

## 1. Framework Wireless Touchpad Keyboard

- 品类：桌面工具（带触控板的无线沙发键盘）
- 来源：Framework 官方预购；The Verge、Notebookcheck、Phoronix 报道
- 链接：[产品页](https://frame.work/products/framework-wireless-touchpad-keyboard) · [官方发布说明](https://frame.work/blog/pre-orders-open-for-framework-wireless-touchpad-keyboard) · [The Verge](https://www.theverge.com/tech/1035805/framework-wireless-touchpad-keyboard-preorder-open)

把 Framework Laptop 12 的键盘模组和 120Hz 精密触控板做成一块可随身用的无线键鼠套件，固件是即将公开的 ZMK 分支，电池可换。增量不是再出一把薄膜键盘，而是把十多年来客厅里凑合着用的 Logitech K400，换成能修、能改键、能切多设备、也能进 BIOS 的现代方案。

解决谁的问题：在客厅、HTPC、家里服务器、树莓派或模拟器座舱前，需要「键盘 + 触控板一体、隔空操作」的人。K400 / K400 Plus 长期卖 $29–35，功能够用但触控板和手感都老了，社区里一直有人等替代。

需求证据：

- 官方 2026-11-17 发文写明，这是 Framework「所有产品里最大的邮件候补名单」。
- 今日打开产品页：Batch 1–10（Q1 2027 发货）和 Batch 11–13（Q2 发货）均显示 Sold Out；Batch 14–15 标为 Q2，页面同时有 Out of stock 提示，是否还能下单以当时页面为准。无论如何，前 13 个生产批次售罄，已经不是营销热度。
- The Verge 引用 Sean Hollister 今年 4 月的上手：认为它对标 K400 的目标基本达到，只是更贵。产品页还引用 t3.gg 的 Theo：他说自己「一直在求一把 K400 的替代」，现在会能买多少买多少。
- 官方对比视频（YouTube，2026-11-17 检索快照）：约 37.0K 播放、1.8K 赞、100 条评论。Phoronix 同日报道下有 26 条评论。

可行性 / 价格：定价 $99，预购先收可退的 $50 定金，余款发货前再收。官方只保证按批次窗口发货，Q1 批次是 1–3 月，不是假日礼物。键盘支持蓝牙多设备、随附 USB-A 接收器和 USB-C 有线；Mac 有单独模式。目前是美式 ANSI 配列。

热度信号：没有众筹总额。候补名单和批次售罄比播放量更硬。

主要风险：价格大约是 K400 的三倍，值不值要等大批量到手评测；Q1/Q2 窗口仍然宽；ZMK 固件「即将」发布到 GitHub，现在还不能验收；若 14–15 批也很快满，交期会继续往后排。

## 2. HackerGadgets RTL-SDR / LoRa / GPS / RTC 四合一树莓派 HAT

- 品类：智能硬件 / 创客扩展板（软件无线电 + Meshtastic + 定位 + 硬件时钟）
- 来源：广州 HackerGadgets 自营店；CNX Software（2026-11-22）、RTL-SDR.com 垂直站
- 链接：[产品说明页](https://hackergadgets.com/pages/rpi-aio) · [CNX Software](https://www.cnx-software.com/2026/11/22/4-in-1-raspberry-pi-hat-combines-rtl-sdr-lora-gps-and-rtc/) · [RTL-SDR.com](https://www.rtl-sdr.com/hackergadgets-releases-a-4-in-1-rtl-sdr-lora-gps-and-rtc-hat-for-the-raspberry-pi/)

一块 HAT 上同时放了 RTL2832U+R860 的 SDR（100 kHz–1.74 GHz，带软件开关的 5V Bias Tee）、SX1262 LoRa（860–960 MHz，宣称支持 Meshtastic）、GPS/北斗定位，以及带可充电纽扣电池的 PCF85063A 实时时钟。针对的是「树莓派上要听无线电、又要跑离网消息、还要在没网时对时」的人，通常得叠几块板、插一个 SDR 棒。

解决谁的问题：做 ADS-B / 气象卫星接收、Meshtastic 节点、车载或便携树莓派的人。树莓派本身没有硬件 RTC，离网日志和定时任务一直要外挂时钟；SDR 棒和 LoRa HAT 再叠上去，天线和供电都会挤。

需求证据：

- RTL-SDR.com 是这块的垂直社区，不是总览科技媒体。编辑写明目前还没有独立评测，但把组合逻辑写得很清楚：GPS + 带电 RTC 对没网的便携 Pi 特别有用。
- 评论区已经在谈下手，而不是转发宣传。有人说「$84，价格不算差」，同时担心散热；有人追问 GNSS 芯片型号，官网没有写清；还有人半开玩笑「就差 PoE 和 NVMe 了」，说明「希望少叠几块板」是真实诉求。
- 同站相关文章里已有给 Clockwork uConsole 用的 SDR/LoRa/GPS/RTC 扩展板，这种四件套不是第一次被做出来，说明需求是重复出现的，不是一次性灵感。

可行性 / 价格：官网标价 $84.90，不含树莓派。页面同时写 In stock 和「这是预购、预计发货日经常变动」，今日看到的预计发货日是 2026-11-27。兼容树莓派 3B/4B/5，Zero / Zero 2 W 在有 40-pin 且供电够的情况下也可装。

热度信号：没有众筹数字。信号来自垂直站首发和评论，不是播放量。

主要风险：还没有第三方实测；GNSS 芯片型号未公布；散热和多天线互相干扰都还没验证；预购交期可能再改。

## 3. CG Deck

- 品类：桌面 / 便携工具（模块化 x86 掌上电脑）
- 来源：Kickstarter（正在众筹），发起方为德州奥斯汀双人团队 Mogozen
- 链接：[Kickstarter 项目页](https://www.kickstarter.com/projects/mogozen/cg-deck-modular-x86-handheld-computer) · [Kicktraq](https://www.kicktraq.com/projects/mogozen/cg-deck-modular-x86-handheld-computer/) · [Hackster 报道](https://www.hackster.io/news/mogozen-s-cg-deck-opens-its-crowdfunding-campaign-promising-an-open-x86-based-handheld-dream-53957a798e20) · [Retro Handhelds](https://retrohandhelds.gg/cg-deck-takes-its-modular-x86-handheld-to-kickstarter-but-mind-the-kit-price/)

5 英寸触摸屏的 x86 掌机，核心是一块 LattePanda IOTA（Intel N150），下面的输入区可热换：键盘、双摇杆手柄、宏键盘，副槽可以插轨迹球，另外还有 USB 摄像头模组。跑 Windows 或 Linux，宣称免焊接更换零件，并承诺在众筹结束后公开 KiCad / 结构文件。增量在「输入模块可换的模块化掌机」，不是再做一台封闭安卓游戏机。

解决谁的问题：既想要 x86 兼容、又想在掌机形态和桌面键鼠之间切换的人，包括改机、cyberdeck、以及记得 PocketCHIP 那种「可拆可玩」路线的人。现在这类需求多半靠自己 3D 打印壳、外接键盘来凑。

需求证据：

- Retro Handhelds 2026-11-19 的报道下，有读者直接评论 “I built my own”，说明这不是凭空想象的品类，已经有人在自制。
- 2026-11-17 上线后不到 48 小时过线。ixbt.games 在 11 月 20 日写到当时已筹 $23,952 / 目标 $20,000。
- 今日 Kicktraq（采集时显示约 2 分钟前更新）：已筹 $28,270 / 目标 $20,000（141%），25 名支持者，人均约 $1,131，周期 2026-11-17 至 2027-01-01，剩余约 39 天。Kickstarter 原页今天没有给出可用数字，金额以 Kicktraq 为准。支持者很少、客单很高，这是小圈层付费，不是大众爆款。

可行性 / 价格：早鸟 DIY 套件 $299，明确不含 LattePanda IOTA。完整早鸟 8GB/64GB 机 $759；Max 8GB/128GB 加全部输入模块和 800 万摄像头 $1,299。今日在 DFRobot 核到 IOTA 零售标价：8GB/64GB $339，16GB/128GB $459，所以 $299 那档买到的不是一台能开机的电脑。预计 2027 年 3 月发货。工程样机今年 5 月后已迭代，开源文件要等众筹结束并完成 DFM 后才公布。

热度信号：已过线，但 25 人、2.8 万美元，和昨天的百万级项目完全不是一个量级。热度只作参考。

主要风险：两人团队的第一款硬件，履约和开源文件落地都还没验证；模块手感和免焊接维修只是宣称；支持者样本太小，后期若成本上涨，高客单方案更容易改价或缩配。

## 4. Marelleo

- 品类：智能硬件 / 开源儿童故事盒
- 来源：Hacker News Show HN（2026-10-27）；作者开源仓库，不是众筹爆款
- 链接：[Show HN 讨论](https://news.ycombinator.com/item?id=50260753) · [GitHub](https://github.com/Zebra-Rodeo/marelleo) · [LockerGnome 整理](https://lockergnome.com/marelleo-open-source-kids-story-box-nfc-figurines-esp32-no-subscription/)

法国家长 Arnaud Aubry 给三个孩子做的 ESP32-S3 故事盒：把带 NFC 标签的手办放上去就播放对应音频，拿开就停。固件、PCB 和外壳都按 MIT 协议公开。没有应用商店，也没有按故事收费。家长在首次开机的本地网页上传 MP3/M4A，或把标签指到网络电台。

解决谁的问题：想给幼儿一个「自己放上去就会讲故事」的盒子，又不想被 Toniebox、Lunii、Yoto 这类「硬件便宜、内容要持续买」的模式绑住的家长。

需求证据：

- Show HN 获 195 分、53 条评论。有人写「等孩子再大一点我也想做」；有人说「这正是我一直想自己做的项目」；还有人今年收到 Toniebox 后，因为锁定内容和隐私问题直接退货，开始找替代。
- 评论区同时列出 TonUINO、ESPuino、Phoniebox，以及给原版 Toniebox 搭自建内容服务器的改装。这说明痛点早就存在，而且长期靠自制和改机在凑合；Marelleo 不是发明了需求，而是又一次把它做完整并写清楚。
- 作者从零学电路，手布 491 根线，在 JLCPCB 花 160 欧元做了 5 块已贴片的板（约合每板 32 欧元），外壳用 Bambu Lab A1 打出来。这是可复现的原型，不是效果图。

可行性 / 价格：不是商店里的 SKU。物料大约是 ESP32-S3-DevKitC-1（约 €15）、PN532（约 €10）、功放、喇叭、3000 mAh 电池等，加上打样的板和 3D 打印件。会 3D 打印的家长可以按文档复刻；目前没有小批量零售。

热度信号：讨论热度在 HN，不在筹款榜。今日用常规抓取看 GitHub 星标不可靠，故不以星标作为依据。

主要风险：仓库还新，作者自己就是售后；固件引脚写死，换板要改代码；默认更新源指向作者服务器，送给别人前需要改掉。它证明需求真实，还不是一个已经验证过的消费产品。

## 值得持续跟踪

- LocalDot / Echo 本地语音改造：XDA 2026-11-20 有一篇上手，把 2 代 Echo Dot 刷成 Home Assistant 语音卫星。文中写得很清楚：4 代目前没有已知利用，3 代要拆机焊测试点，而且新固件有变砖风险。这反而说明「直接换一块本地主板、不走破解」的 LocalDot 路线，仍然对准了那部分不想拆机、又堆了多台 3 代 Dot 的人。

- 妙动 Beni 跟拍机器人：继续零售跟踪，无新的关键进展需要改判断。

## 采集说明

今天需求证据最硬的是 Framework 键盘（官方承认最大候补 + 多个生产批次售罄），其次是 HackerGadgets 这块在垂直评论区被认真询价的扩展板。CG Deck 形态有意思，但 25 名支持者决定了它只能当小圈层信号。Marelleo 用来补「社区里已经有人用自制在绕」这类证据，不把它写成即将量产的商品。

国内众筹和社区仍是缺口：摩点、有品没有达标新品；京东众筹、恩山、知乎、RCGroups、Reddit 垂直版块今天仍未稳定打开。Crowd Supply 连续两天 403，已改用 LinuxGizmos、Hackster、RTL-SDR.com 和官方自营店补，不再假装已经读到原页。

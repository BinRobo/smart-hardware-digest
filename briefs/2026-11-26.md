## 1. TokenTV

- 品类：智能硬件 / 桌面工具（把现成 Wi-Fi 时钟当成 Agent 状态小屏）
- 来源：Show HN（2026-11-25）；GitHub；Hackaday（2026-10-06 已写过，今日补报）
- 链接：[GitHub](https://github.com/click6067-ship-it/token-tv) · [Show HN](https://news.ycombinator.com/item?id=50642300) · [Hackaday 10-06](https://hackaday.com/2026/10/06/smalltv-hacking-with-surprisingly-little-fuss/) · [Hackster](https://www.hackster.io/click6067/claude-and-codex-usage-on-a-5-wi-fi-clock-stock-firmware-65b8e4)

不是再做一个桌面宠物，而是不刷固件、不焊接，利用 GeekMagic SmallTV 自带的相册页，把 240×240 的图片从常开电脑推到一块大约 5–13 美元的现成时钟上。Clawd 会在 Claude 要你批准时举手，同时把用量额度放在眼前。

解决谁的问题：并排跑 Claude Code / Codex 的人，不想为了一块状态屏再买一套开发板，也不想给廉价时钟刷机变砖。现在有人用第二个显示器或手机通知凑合，也有人走哈基米机那种「自己做一块屏」的路。TokenTV 是更省事的第三条路：买现成钟，软件接上就用。

需求证据：

- 谁、什么场景：经常并排跑编码 Agent、希望抬眼就能看到「是不是在等我、额度还剩多少」的人。
- GitHub 仓库 `click6067-ship-it/token-tv` 今日 API（约 09:40 UTC+8）为 **123 star、17 fork、10 个 open issues**，许可证 MIT。最近一次 push 为 2026-11-24 17:58 UTC；`updated_at` 为 2026-11-26 01:18 UTC（当天 09:18 UTC+8）。
- 独立用户已经在真机上验证并提交补丁。yethihahtwe 为 SmallTV-Ultra 做了支持（[PR #7](https://github.com/click6067-ship-it/token-tv/pull/7)，6 条评论，并在 9.1.54 预发布固件上拍了视频）；okalentiev 补了全新 Ultra 还没有 `/app.json` 时的备份（[PR #10](https://github.com/click6067-ship-it/token-tv/pull/10)），还做了 5 小时和周额度并排的表盘；sym0nd0 在 2026-11-19 确认 Ultra-V9.0.51 可用（[Issue #13](https://github.com/click6067-ship-it/token-tv/issues/13)）。这是跟做，不是只点星。
- Hackaday 2026-10-06 的评测下，Casey 说自己已经有一台、正打算自己画界面；David 愿意花 20 美元买带电池的电子纸门牌版；有人指向 Home Assistant 里现成的 [geekmagic-hacs](https://github.com/adrienbrault/geekmagic-hacs)。评论区要的是「这块屏还能干什么」，不是官方演示。

热度信号：Show HN 发布于 2026-11-25 21:51（UTC+8），Algolia 记录为 **34 分、0 条评论**（story id 50642300）。传播热度一般，需求看上面的真机适配。

可行性 / 价格：时钟通常在 AliExpress 卖大约 5–13 美元，作者自己的 SD_PRO 约 4 美元（₩5,650）。软件 MIT，`npx token-tv start` 即可。不卖整机。

主要风险：必须有一台同网段常开电脑推图；厂商改相册接口或固件会直接打断，所以才有一串固件版本适配；Claude Code 反应插件目前只支持 macOS / Linux，不含 Windows；这是社区软件项目，不是量产 SKU。它和 11-24 的哈基米机、SlashVibe 打同一类需求，今天单列是因为「不刷机、用现成时钟」这条路径是新的，不再重复报桌面宠物本身。

## 2. CANBUS Stepper（及同门的 PD Stepper）

- 品类：桌面工具 / 开源运动控制（贴在 NEMA 17 背后的闭环驱动板）
- 来源：作者自营小店 Things by Josh；Hackaday 2026-11-25
- 链接：[CANBUS 商品页](https://thingsbyjosh.com/products/canbus-stepper) · [PD Stepper 商品页](https://thingsbyjosh.com/products/pd-stepper) · [CANBUS GitHub](https://github.com/joshr120/CANBUS-Stepper) · [PD Stepper GitHub](https://github.com/joshr120/PD-Stepper) · [Hackaday](https://hackaday.com/2026/11/25/daisy-chaining-stepper-motors/)

把驱动、ESP32-S3、编码器和电源接口做到 42×42×14 mm 的电机背板上。CANBUS 版用两线 CAN 像灯带一样串起来，最多约 31 个节点；一块板用 USB / Wi-Fi / CAN / 串口接入后，把指令传给后面的电机。不是再出一块桌面多轴控制箱。同门的 PD Stepper 更早，一块板插 USB-C PD 充电器就能转一颗电机，适合单轴。

解决谁的问题：做多轴滑台、小型机器人和自动化夹具的人。现在要么把一堆驱动和电源堆在机箱里，要么为每台电机单独配控制器和线材。希望「电机后面自带脑子，电源和通讯一串到底」。

需求证据：

- 谁、什么场景：已经在用 NEMA 17 做小型运动机构，又不想再配一套控制柜的创客和设备搭建者。
- PD Stepper 仓库 `joshr120/PD-Stepper` 今日 API 为 **958 star、123 fork**，许可证 GPL-3.0，2024 年 6 月开源。Issue 里是用过的人：[Issue #53](https://github.com/joshr120/PD-Stepper/issues/53) 有人收到板后开机循环，刷固件后恢复；[Issue #52](https://github.com/joshr120/PD-Stepper/issues/52) 要求文档写清兼容哪几种 NEMA 17。这是出货后的使用问题，不是宣传。
- CANBUS 仓库 `joshr120/CANBUS-Stepper` 今日 API 为 **41 star、5 fork**，最近一次 push 为 2026-11-20 09:11 UTC。[Issue #1](https://github.com/joshr120/CANBUS-Stepper/issues/1) 从 7 月问到 10 月，是在讨论 PCB。
- Hackaday 今日评测下，Nathan 写自己「找了很久」想要这类闭环板，但希望兼容 CiA 402 CANopen，好跟现成控制器互通；做不到这一点会让他继续观望。这是垂直用户的真实门槛，不是点赞。

热度信号：作者「Upgrading the PD Stepper」视频的检索快照约为 15.2K 播放、818 赞（发布于 2025-04-09）。CANBUS 本身没有众筹额，看的是小店是否能持续出货。

可行性 / 价格：今日打开的商品页，CANBUS Stepper V2 为 **NZ$125**，PD Stepper 全套 **NZ$110**、简装 **NZ$85**（电机另配，全球运）。部分检索快照以美元显示（约 US$70 / US$62），以结算页为准。PD Stepper 首页标明 In Stock；CANBUS 商品页写着 **On backorder**，预估发货日期仍显示 **2026-11-13**，这一天已经过去，所以只能当成「仍在缺货、交期页没改」，不能写成即将到货。

主要风险：CANBUS 缺货且页面交期过期；Hackaday 评论指出尚未做 CiA 402，和工业控制器的互操作性有限；板子贴在电机背后，散热和批量一致性要靠实际装机验证。同一商店的四口 60W / 10Gbps USB 集线器仍是 Coming Soon，今天不列入。

## 3. Checkmate Display Batch 2

- 品类：桌面工具（可升级的复古造型 IPS 显示器）
- 来源：Kickstarter（2026-11-25 刚收官）；复古计算社区 The Oasis BBS
- 链接：[Kickstarter 项目页](https://www.kickstarter.com/projects/checkmateproducts/retro-styled-ips-display-internally-upgradeable-batch-2) · [The Oasis BBS 11-20](https://theoasisbbs.com/checkmate-display-batch-2-brings-rgb-scart-to-the-standard-monitor/)

19 英寸、1280×1024、5:4 的 IPS 监视器平台，背板可加模块。Batch 2 的增量是把 15 kHz RGB SCART 收进标准机，不再为了接 Amiga / Atari ST 再买一块扩展。同时保留双复合、HDMI 进出和 31 kHz VGA，并支持 PAL 50 Hz / NTSC 60 Hz。

解决谁的问题：还在用 Amiga、Atari ST、ZX Spectrum Next、C64（复合）以及准备上 MiSTer / 树莓派套件的人。普通 HDMI 显示器要另加扫描线转换器，老 CRT 难修、占地方。这是第二生产批次，说明第一批已经有人买过，还想再买或补接口。

需求证据：

- 谁、什么场景：仍在维护 8 位 / 16 位机器和 FPGA 复古套件、需要 15 kHz RGB 和 5:4 面板的爱好者。
- Kickstarter 原页今日能打开，官方结算为 **966 名支持者，已筹 £338,397 / 目标 £195,000（约 173%）**，周期 2026-10-26 至 2026-11-25。人均约 £350，买的是整机不是周边。
- 复古 BBS The Oasis 11 月 20 日专门写了「标准机终于自带 RGB SCART」这件事，并提醒 C64 没有 RGB、S-Video 仍要选 Pro Pack。这是圈内人在对接口，不是旅行评测。
- Indie Retro News 等在 11 月 20 日转发「已经成功」，并提到会配 ZX Spectrum NEXT 3。

热度信号：金额中等，不是百万级。PledgeBox 较早快照是 870 人 / £299,066，与收官数字不同，以官方页为准。

可行性 / 价格：Oasis 按 2026-11-20 汇率记标准机约 496 美元（黑 / 白），Pro Pack 约 234 美元（事后单独卖，加 component / S-Video / RF / CGA），MiSTer 和树莓派安装套件约 51 美元。另有约 131 美元的 Festive Placeholder 订金，官方说是不可退的认购承诺，不是更便宜的显示器。预计 2027 年 8 月发货，运费和税另计。

主要风险：交期长；第二批次仍是众筹交付；Placeholder 不可退；1280×1024 的 HDMI 输出对采集设备不友好。

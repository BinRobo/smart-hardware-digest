## 1. Mural V2

- 品类：桌面 / 墙面工具（开源缆绳式墙面绘图机器人）
- 来源：作者 Nik Ivanov 开源仓库与演示视频；Hackster 2026-11-24 报道
- 链接：[项目主页](https://getmural.me/) · [GitHub](https://github.com/nikivanov/mural) · [Hackster](https://www.hackster.io/news/mural-v2-can-automatically-create-wall-size-art-on-a-budget-87f92070ce73) · [V2 演示视频](https://www.youtube.com/watch?v=Hjp9P1Shx5E)

不是再做一台导轨桌面笔绘机，而是用两个顶角锚点、两条 GT2 皮带和 3D 打印滑车在墙上画大幅马克笔作品。V2 改用带 TMC2209 的 FluidNC / ESP32 控制板，网页在本地自托管，上传矢量或光栅图后一键开画。增量在「便宜、好装、零件常见」，针对的是以前那些贵且不好用的众筹墙绘机。

需求证据：

- 谁、什么场景：想在家里或工作室墙上出画、又不想请画师、也不想再买一台贵而不稳的众筹墙绘机的创客和爱好者。
- GitHub 仓库 `nikivanov/mural` 今日 API（约 09:32 UTC+8）为 **748 star、141 fork、25 个 open issues**，最近一次 push 为 2026-11-25 01:08 UTC（当天 09:08 UTC+8）。
- 真正硬的信号是跟做卡在官方指定控制板上。Issue [#100](https://github.com/nikivanov/mural/issues/100)（2026-11-12）写明 FluidNC TMC2209 笔/激光板在美国以外很难买到，Tindie 上显示可能已停产；德国用户在后续评论里说，如果没有欧洲也能买到的替代板，「Mural 2.0 就只能先放下了」。作者回复将改用更常见的开源板 MKS DLC32，但明确给不出完成时间，而且已打印的 V2 外壳底部和盖板可能要换。[#103](https://github.com/nikivanov/mural/issues/103)、[#105](https://github.com/nikivanov/mural/issues/105) 是同一缺货问题；已有人在做 [PR #108](https://github.com/nikivanov/mural/pull/108)（MKS DLC32 V2.1 固件和外壳）。
- 视频评论区里有人提到多年前买过昂贵 Kickstarter 墙绘机、几乎不能用，一直在等开源方案；也有人问作者能不能直接卖成品。这是跟做和购买意向，要和播放量分开看。

热度信号：今日打开的 V2 视频页源码为 **1,192,362 次播放、15,001 赞**，2026-11-11 发布。这是传播热度。需求热度看上面的缺货和替代方案讨论。

可行性 / 价格：全部是现成件（控制板、两颗薄型 NEMA 17、舵机、USB-C 供电、3D 打印件、可水洗马克笔等），没有官方 BOM 总价。此前有媒体把初代写成 100 美元以内，不能直接当成 V2 现价。可行性的卡点已经出现：指定主板缺货，替代方案还在做。

主要风险：指定控制板停产或长期缺货会打断跟做；目前只支持马克笔；大画幅边缘精度仍缺系统性实测。

## 2. Unexpected Maker Smart USB Hub

- 品类：桌面工具 / 开发测试硬件（6 口智能 USB 集线器）
- 来源：Pimoroni 现货零售；Unexpected Maker 开源仓库（非头部众筹）
- 链接：[Pimoroni 商品页](https://shop.pimoroni.com/products/smart-6-port-usb-hub) · [GitHub](https://github.com/UnexpectedMaker/um_smart_usb_hub_6)

6 个 USB-C 下游口（USB 2.0），由 ESP32-S3 通过 Wi-Fi 控制：每口独立供电开关、实时电压/电流/功率监测、按口日程，并提供网页和 REST API。给测试脚本或长时间挂机的 USB 设备做断电重启，不用反复拔插。

需求证据：

- 谁、什么场景：做嵌入式测试、需要让 USB 设备在挂死或做循环上电时按口远程断电的开发者和实验室；也可以给需要定时上下电的 USB 外设做工作台调度。
- 品类痛点是真实的。例如 r/embedded 在 2026 年 8 月左右有帖 [USB Hub Controllable from PC for Embedded Test](https://www.reddit.com/r/embedded/comments/1veg5ns/usb_hub_controllable_from_pc_for_embedded_test/)，发帖人要测一批设备，USB 挂死时希望用脚本按口断电重启。该帖评论区今日未能打开，所以不能把回帖内容写成已核事实。
- 针对这一款本身，公开讨论还薄：GitHub 今日 API 为 **10 star、6 fork、2 个 open issues**，最近一次 push 为 2026-11-19 23:22 UTC（11-20 07:22 UTC+8）。作者 2026-11-05 在 X 上说三批订单/预购已经发完，并有现货；Pimoroni 于 11 月中旬上架，11-18 对外介绍。这更像既有小批量产品进入主流创客零售渠道，而不是本周才出现的全新发明。需求方向成立，但「社区反复点名这一款」的证据仍中等。

热度信号：不是排行榜爆款。可见信号是 Pimoroni 现货上架和开源仓库更新。

可行性 / 价格：Pimoroni 今日页面为现货。英国站 Board Only **£35**、With Case **£47.50**；美元站 Board Only **$47**、With Case **$64**。开源（KiCad、PlatformIO 固件、外壳 STEP）。作者 Unexpected Maker 长期出板，可行性较好。每口硬件限流 680 mA，电源需另配 5V USB-C 3A 以上适配器。

主要风险：只有 USB 2.0、单口 680 mA，不适合当充电坞或高速硬盘坞；软件软限流还在后续固件里；独立长评很少。
